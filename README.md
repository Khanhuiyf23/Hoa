# Hướng dẫn học Hóa 12 (Frontend)

Website học tập Hóa 12 bằng **HTML/CSS/JavaScript thuần**, tối ưu mobile-first, có:
- Danh sách chuyên đề + trang chi tiết
- Tìm kiếm, lọc dạng học liệu
- Trắc nghiệm theo chuyên đề, chấm điểm tức thì
- Dark mode, lưu tiến độ học và danh sách yêu thích bằng localStorage

## Cách chạy

Vì là frontend thuần, bạn chỉ cần mở file `index.html` trong trình duyệt.

Gợi ý chạy với local server:

```bash
python3 -m http.server 5500
```

Sau đó truy cập: `http://localhost:5500`
